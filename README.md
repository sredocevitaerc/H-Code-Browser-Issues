# H-Code Browser Extension Issue Tracker

This public repository is the support and bug tracker for the H-Code browser extension for ChatGPT and Claude.

## Report a Bug

[Open a structured bug report](https://github.com/sredocevitaerc/H-Code-Browser-Issues/issues/new?template=bug-report.yml)

Before submitting:

1. Search open and closed issues for the same problem.
2. Confirm the problem is reproducible.
3. Collect the H-Code version, browser and version, operating system, affected site, and the steps that cause the problem.
4. Remove credentials, tokens, conversation content, account IDs, and private links from screenshots or logs.

## Scope

Use this repository for H-Code browser extension problems, including project or chat sync, sidebar state, account actions, and Chrome or Firefox compatibility. For suspected security vulnerabilities, follow [SECURITY.md](SECURITY.md) and report privately.

This repository is separate from the [JetBrains plugin issue tracker](https://github.com/sredocevitaerc/H-Code-JetBrains-Issues).

## Source Code

The H-Code browser extension source repository is currently private. This public tracker intentionally contains no extension source code, credentials, signing material, or store secrets.
