# H-Code Browser Extension Support

H-Code adds a sidebar to chatgpt.com and claude.ai that shows your projects and chats as numbered, nested folders. This page explains how to get help.

**Issues:** <https://github.com/sredocevitaerc/H-Code-Browser-Issues/issues>

## Report a problem

[Open a bug report](https://github.com/sredocevitaerc/H-Code-Browser-Issues/issues/new?template=bug-report.yml)

Before you submit:

1. Search [open and closed issues](https://github.com/sredocevitaerc/H-Code-Browser-Issues/issues?q=is%3Aissue) for the same problem.
2. Note your H-Code version (shown on your browser's extension details page), your browser and its version, your operating system, and the site (ChatGPT or Claude).
3. Write the steps that cause the problem.
4. Remove credentials, tokens, conversation content, account IDs and private links from screenshots and logs. Issues are public.

## Questions and suggestions

Ask questions or suggest features in the [issue tracker](https://github.com/sredocevitaerc/H-Code-Browser-Issues/issues). Search first, in case it has already been answered.

## Common fixes

- **The H-Code button does not appear:** reload the ChatGPT or Claude page. Check that the extension is enabled and allowed to run on chatgpt.com and claude.ai in your browser's extension settings.
- **Projects or chats are missing or out of date:** make sure you are signed in on the site, then reload the page so H-Code syncs again.
- **The sidebar looks wrong after an update:** reload the page. If it continues, clear the extension's data in your browser. This resets the sidebar only; it does not change anything in your ChatGPT or Claude account.

## Security and privacy

Report a suspected security vulnerability privately, as described in [SECURITY.md](https://github.com/sredocevitaerc/H-Code-Browser-Issues/blob/main/SECURITY.md), not in a public issue.

Read the [privacy policy](PRIVACY.html) for what H-Code reads and stores. For a private matter, use the contact information on the [maintainer's GitHub profile](https://github.com/sredocevitaerc).
